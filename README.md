# Swiggy Clone 🍕🍟

A clean and responsive frontend clone of the Swiggy food delivery platform's user interface, built entirely using semantic HTML5 and custom CSS3.

## 🚀 Live Demo
You can view the live deployment of this project here:
👉 **[Live Demo Link](https://polojuarunkumar.github.io/swiggy_clone/)**

---

## ✨ Features
* **Responsive Layout:** Designed to look great across different screen sizes (Desktop, Tablet, Mobile).
* **Pixel-Perfect UI:** Replicates the clean aesthetic of Swiggy, including navigation headers, search layout, and food cards.
* **Modern CSS Components:** Utilizes CSS Flexbox/Grid for layout alignments and smooth hover effects on interactive elements.

---

## 🛠️ Tech Stack
* **HTML5:** For structured, semantic web content.
* **CSS3:** For custom styling, layout structures, and responsive media queries.
